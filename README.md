# freee 勤怠レポート

freee 人事労務 API と連携し、**当月の勤怠データを自動取得して Excel レポートをワンクリックで生成**する Streamlit 製 Web アプリです。

---

## 主な機能

- freee アカウントで OAuth 認証（リダイレクト後に認可コードを自動取得）
- 所属会社を選択するだけで、当月分の勤怠データ（始業・終業・休憩・有給・半休）を自動取得
- 任意で **契約名** を入力してテンプレートに反映
- 所定のテンプレート「作業実施報告書」に転記し、氏名入りの Excel ファイルとしてダウンロード
- 60 名規模のチームでの同時利用を想定（セッションごとに独立したトークン管理・メモリ上でファイル生成）

---

## Excel への転記仕様

| セル | 内容 |
| --- | --- |
| K3 | 契約名（任意入力。空欄可） |
| K5 | 作業者の苗字（freee 登録の姓） |
| L5 | 作業者の名前（freee 登録の名） |
| K8 | 対象月の初日（例: 2026/04/01） |
| L8〜 | 曜日（テンプレート側の数式で自動表示） |
| M8〜 | 開始時刻 |
| N8〜 | 終業時刻 |
| O8〜 | 休憩時間 |
| H8〜 | 備考（有給・半休の場合に自動記載） |

---

## 有給・半休の自動判定

freee API のレスポンスをもとに有給・午前休・午後休を判定し、備考欄と勤怠時刻欄に以下を出力します。

| 状態 | 備考 | 開始-終業 | 休憩 |
| --- | --- | --- | --- |
| 全日有給 | 「有給取得」 | - | - |
| 午前休 | 「午前休取得」 | 打刻時刻を転記 | 休憩時間（無ければ 0.0） |
| 午後休 | 「午後休取得」 | 打刻時刻を転記 | 休憩時間（無ければ 0.0） |
| 通常勤務日 | 自動なし（祝日のみテンプレート側で表示） | 打刻時刻を転記 | 合計休憩時間 |

> ⚠️ 有給・半休は freee 側で **「申請 → 承認」が完了している** 必要があります。承認待ちのデータは API では取得できません。

---

## 使い方

1. 画面の **「freee 認証ページを開く」** をクリック
2. freee でログインし、認可を実行（リダイレクト後は自動で認証完了）
3. 対象会社を選択
4. 必要に応じて **契約名** を入力（空欄可）
5. **「データ取得 & Excel 作成」** をクリック
6. 生成された Excel を **「Excel をダウンロード」** で取得
